# dns-paso-a-paso

## Autor
Antonio Jiménez Balbuena

## Proposito
Hacer un servidor DNS sobre debian con vagrant

## Como ejecutarlo
Clonar el proyecto git clone https://github.com/Antonio2907/dns-paso-a-paso.git
Entrar en el directorio y arrancar la maquina con vagrant up.
Si al terminar la ultima provision ejecuta test.sh y muestra si la configuracion y las resoluciones son correctas,
por lo tanto estaria todo correcto.
